# TODO / Roadmap

Ideas for future work, grouped by effort and dependencies.

## Completed

### Show List: attribute icon column improvements [DONE]
- All six attribute icons now appear on every row using Font Awesome fixed-width
  style (fa-fw). Icons that do not apply to a show are greyed out at 18% opacity.

### Show List: mobile card layout [DONE]
- On screens 700px and narrower the table switches to stacked cards.
- Each show renders as a block: dark header bar with date + cal button, then
  labeled lines for bands, venue, age, price, time, attrs, and notes.
- No horizontal scrolling required.

### Show info: add-to-calendar button (per show) [DONE]
- A calendar-plus button appears on every show in the table, the map venue
  panel, and the calendar day panel.
- Clicking downloads a .ics file generated on the fly in the browser.
- Timed events use the listed show time with a 2-hour assumed duration.
  Shows with no parseable time fall back to an all-day event.
- downloadIcs() lives in assets/common.js so all three pages share one copy.

### Collapsible sidebar on desktop (map + calendar) [DONE]
- A small toggle handle sits on the left edge of the sidebar on map.html and
  calendar.html. Clicking it slides the panel closed and widens the content
  area. Clicking again reopens it.
- initCollapsiblePanel() lives in assets/common.js, called by both page files.

### Code refactor: shared CSS + JS [DONE]
- All CSS moved to assets/styles.css (one copy, all pages).
- Shared JS helpers moved to assets/common.js (TheList global object).
- Per-page logic split into assets/page-list.js, page-map.js, page-calendar.js.
- HTML files are now markup-only (under 5KB each).

### About page [DONE]
- about.html credits Steve Koepke and lists the symbol legend.
- Linked from the nav on all four pages.

### CSV files removed [DONE]
- data/shows.csv and data/venues.csv removed. JSON is the single source of truth.
- Pages only ever read the JSON; CSVs were unused and could drift out of sync.
